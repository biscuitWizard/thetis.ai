# D20 advantage and disadvantage

With advantage, roll two twenty-sided dice and use the higher result. With disadvantage, use the lower. Several favorable sources still produce only two dice, as do several unfavorable sources. If at least one source of each applies, they cancel and the roll uses one die unless a more specific rule says otherwise.
