# D20 ability checks

Call for a check only when success is uncertain and failure changes the situation. Roll one twenty-sided die, add the modifier for the ability that best represents the approach, and add proficiency if relevant training applies. The action succeeds when the total equals or exceeds the chosen difficulty.
