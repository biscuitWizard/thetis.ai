# D20 difficulty classes

Choose the target from the obstacle as established in the fiction. Routine actions need no roll. Use a lower target for a modest challenge and a higher one for a task that would test a capable adventurer; reserve extreme targets for exceptional feats. Prefer advantage or disadvantage when circumstances affect execution rather than the obstacle itself.
