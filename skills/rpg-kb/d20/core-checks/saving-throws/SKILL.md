# D20 saving throws

A saving throw is a reactive check against an imposed danger. The effect names the ability and target. Roll a twenty-sided die, add that ability's modifier, and add proficiency only if the character is trained in that category of save. Meeting the target resists the threat fully or partially as the effect specifies.
