# D20 Armor Class

Armor Class is a target number, not a damage reduction roll. Build it from the character's equipped protection, permitted agility contribution, shield, and temporary effects. An attack connects when its total equals or exceeds this defense. Use the single best applicable base formula unless a feature explicitly allows formulas to combine.
