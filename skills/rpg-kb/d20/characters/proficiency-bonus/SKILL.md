# D20 proficiency bonus

Proficiency represents relevant training. Add the character's proficiency bonus when a rule grants training for the check, save, attack, or tool use. Add it only once even when several features grant proficiency in the same task. A feature that explicitly doubles proficiency modifies that single contribution rather than creating a second one.
