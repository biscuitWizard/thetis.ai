# D20 rest and recovery

A rest requires enough uninterrupted safety and time to recover. A short rest permits only the healing and feature refreshes that explicitly name it. A long rest restores the broader set defined by the campaign and cannot normally be repeated for unlimited benefit without meaningful adventuring time between rests. An interruption can delay or cancel recovery at the referee's judgment.
