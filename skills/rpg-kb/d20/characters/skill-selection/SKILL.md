# D20 skill selection

First identify what the character is doing and choose the ability that matches that approach. Then decide whether one of the character's trained skills materially helps. A skill name does not force one ability in every situation: a different approach can justify a different ability. If no listed skill fits, make an untrained ability check rather than inventing a mandatory category.
