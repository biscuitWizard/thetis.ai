# If a Skill Check fails, a player cannot simply try again unless

If a Skill Check fails, a player cannot simply try again unless they have improved their chances, such as taking more time, using better tools, or receiving assistance from someone with Complementary Skills. Complementary Skills allow a successful roll in one skill to provide a +1 bonus to a subsequent related Skill Check, but this bonus is only applicable once and does not stack.
