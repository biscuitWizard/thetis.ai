# Modifiers can affect Skill Checks by either making them easier or more

Modifiers can affect Skill Checks by either making them easier or more challenging. Negative Modifiers are applied during difficult conditions such as poor lighting, exhaustion, or extreme stress, making the Skill Check harder by subtracting the Modifier Value from the roll. For example, working under dark conditions might incur a -1 Modifier.
