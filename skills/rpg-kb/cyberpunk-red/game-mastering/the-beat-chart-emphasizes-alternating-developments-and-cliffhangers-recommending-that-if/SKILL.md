# The Beat Chart emphasizes alternating developments and cliffhangers, recommending that if

The Beat Chart emphasizes alternating developments and cliffhangers, recommending that if the hook involves action, the next should be a development, and vice versa. Additionally, if the climax is action-packed, it should conclude with a development, or with a cliffhanger if the climax is more cerebral.
