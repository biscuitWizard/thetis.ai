# Cyberpunk Red offers different methods for generating character statistics using

Cyberpunk Red offers different methods for generating character statistics using templates tailored to specific roles. The Streetrat method involves rolling a 1d10 to determine a set of pre-generated optimal stats for a chosen character role, such as Solo, Rockerboy, Netrunner, and others. Each roll corresponds to a specific stat pattern which must be followed without rearrangement. The Edgerunner method allows for more customization by rolling a 1d10 for each stat individually within the template of a specific role. This provides a balance between fixed templates and more flexible character builds. Each individual stat is determined by the roll compared to the column for that stat in the role's template. These methods are designed to quickly establish a character's starting attributes while ensuring viability within their chosen role, reflecting the character's inherent capabilities in the world of Cyberpunk.
