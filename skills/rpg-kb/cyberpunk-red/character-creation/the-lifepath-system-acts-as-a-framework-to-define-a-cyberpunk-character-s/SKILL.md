# The Lifepath system acts as a framework to define a Cyberpunk character's

The Lifepath system acts as a framework to define a Cyberpunk character's cultural origins, personality, style, and motivations. It uses tables where players roll dice to decide aspects like cultural background, languages spoken, personality traits, and personal style, encouraging a detailed and varied background for each character.
