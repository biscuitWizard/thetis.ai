# The character creation process in Cyberpunk RED involves picking a Role, running

The character creation process in Cyberpunk RED involves picking a Role, running a Lifepath for background details, setting statistics (or buying them in the Complete Package), selecting skills, and equipping with weapons, armor, gear, and cyberware. Derived statistics are calculated as part of this process, adding depth to character capabilities and personalization.
