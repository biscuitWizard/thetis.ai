# The DataKrash was a catastrophic event in which a computer viral plague,

The DataKrash was a catastrophic event in which a computer viral plague, unusually named the DataKrash, was created by the anarchic genius and Netrunner, Rache Bartmoss. This viral plague randomized, erased, and rewrote data uncontrollably, essentially dismantling the structure of global information networks that was integral to both governments and Megacorporations. The DataKrash plunged the world into chaos, as societal infrastructure reliant on information technologies collapsed.
