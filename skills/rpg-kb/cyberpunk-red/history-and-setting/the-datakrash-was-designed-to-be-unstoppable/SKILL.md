# The DataKrash was designed to be unstoppable

The DataKrash was designed to be unstoppable. Rache Bartmoss ensured it by embedding the viral code in the necessary algorithms for the NET to function, making it inherent in the NET's operations. His cleverly disguised backdoor in the I-G Transformations resulted in the DataKrash infecting every system using these protocols without needing to 'spread' as conventional viruses do. The ramifications were immense, sparking global chaos.
