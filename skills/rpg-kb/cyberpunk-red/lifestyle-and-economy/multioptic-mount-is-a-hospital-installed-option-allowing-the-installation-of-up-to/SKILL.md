# MultiOptic Mount is a hospital-installed option allowing the installation of up to

MultiOptic Mount is a hospital-installed option allowing the installation of up to 5 additional Cybereyes. Only one MultiOptic Mount can be installed, costing 1,000 eb and causing 14 humanity loss.
