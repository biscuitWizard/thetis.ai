# The Backup Drive is a Cyberdeck hardware option that saves destroyed Non-Black

The Backup Drive is a Cyberdeck hardware option that saves destroyed Non-Black ICE Programs for reinstallation. It uses 2 hardware slots and costs 100 eb.
