# Anti-Dazzle is an upgrade for Cybereyes that requires two paired Cybereyes

Anti-Dazzle is an upgrade for Cybereyes that requires two paired Cybereyes. It immunizes the user against blindness or blinding flashes from sources like flashbangs.
