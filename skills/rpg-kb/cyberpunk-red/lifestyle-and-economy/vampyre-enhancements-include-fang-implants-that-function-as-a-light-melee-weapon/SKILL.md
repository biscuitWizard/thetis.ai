# Vampyre enhancements include fang implants that function as a Light Melee Weapon

Vampyre enhancements include fang implants that function as a Light Melee Weapon. They can store poison vials safely, which can be applied silently without an action, and they include changes to the mouth to prevent self-poisoning.
