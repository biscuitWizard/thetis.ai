# Cyberdeck integration is a Cyberarm Option allowing the installation of a Cyberdeck

Cyberdeck integration is a Cyberarm Option allowing the installation of a Cyberdeck directly into the Cyberarm. This grants the deck an additional option slot for Programs or Hardware and is considered a permanent upgrade, though uninstalling it breaks the Cyberdeck. The Cyberdeck still needs Interface Plugs and a Neural Link to function.

Source path for review: Cyberpunk RED Core Book > Lifestyle and economy > Black ICE [summary; loc 906238].
