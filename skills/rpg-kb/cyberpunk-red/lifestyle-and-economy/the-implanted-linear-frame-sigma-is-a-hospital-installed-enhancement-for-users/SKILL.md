# The Implanted Linear Frame Σ (Sigma) is a hospital-installed enhancement for users

The Implanted Linear Frame Σ (Sigma) is a hospital-installed enhancement for users to boost their BODY stat to 12, consequently altering HP and Death Saves. This enhancement cannot increase BODY beyond 12, requires BODY 6, and costs 1,000 eb, along with 14 humanity loss.
