# The Tsunami Arms Helix is a luxury exotic assault rifle that requires

The Tsunami Arms Helix is a luxury exotic assault rifle that requires 5,000eb. It functions exclusively using the Autofire Skill, consuming 20 bullets per attack from a 40-bullet magazine. If successful, damage is calculated by multiplying the 2d6 roll by how much the user exceeds the required DV, up to 5 times. It can only be reloaded with two actions, requiring a body stat of 11+ unless mounted.
