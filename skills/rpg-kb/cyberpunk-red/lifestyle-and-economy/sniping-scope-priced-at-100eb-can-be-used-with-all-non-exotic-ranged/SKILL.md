# Sniping Scope, priced at 100eb, can be used with all non-exotic ranged

Sniping Scope, priced at 100eb, can be used with all non-exotic ranged weapons to offer a detailed view up to 800m/yds and a +1 bonus for ranges over 51m/yds. It does not stack with TeleOptics Cyberware.
