# The Edgerunner method for Skills in the game allows players to start

The Edgerunner method for Skills in the game allows players to start with predetermined Skills for their Role but provides flexibility for the player to decide the level of each Skill. Players have 86 Skill points that can be distributed among the available Skills for their Role, with each Skill costing one point per level increase, except for certain marked Skills which cost two points per level. These Skills cannot be higher than 6 or lower than 2. Additionally, each character receives 4 levels of a Language based on their Cultural Origin for free.
