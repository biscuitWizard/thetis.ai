# Martial Arts skill allows a character to fight with a particular martial

Martial Arts skill allows a character to fight with a particular martial art form. Each improvement in this skill requires focusing on one form such as Karate, Taekwondo, Judo, or Aikido. At Base 10, a character is trained in basic movements. At Base 14, they can execute special moves and combos. At Base 18, they are a master comparable to legends like Bruce Lee.
