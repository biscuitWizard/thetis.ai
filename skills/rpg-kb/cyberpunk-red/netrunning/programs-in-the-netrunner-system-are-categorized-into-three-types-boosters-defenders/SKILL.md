# Programs in the NETRUNNER system are categorized into three types: Boosters, Defenders,

Programs in the NETRUNNER system are categorized into three types: Boosters, Defenders, and Attackers. Boosters improve abilities in NET Architecture while active, Defenders stop or reduce the attacks from enemy Programs or Netrunners, and Attackers are designed to damage or disable Programs or Netrunners. Programs need to be activated each round, and can be stacked if multiple copies are used, except for Defenders that can only run one at a time per Netrun.
