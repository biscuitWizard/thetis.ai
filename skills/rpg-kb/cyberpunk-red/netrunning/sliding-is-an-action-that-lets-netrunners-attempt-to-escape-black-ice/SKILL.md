# Sliding is an action that lets Netrunners attempt to escape Black ICE

Sliding is an action that lets Netrunners attempt to escape Black ICE programs in a NET architecture. This requires rolling Interface vs. the ICE's perception, allowing one escape attempt per turn. Successful use can move a Netrunner to a safer area.
