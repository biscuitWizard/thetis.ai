# A Netrunner can attack using the Zap ability in a NET Action,

A Netrunner can attack using the Zap ability in a NET Action, targeting a program or another Netrunner. Rolling an attack check against the opponent’s defense and succeeding deals damage to the target's REZ or the Netrunner's brain.
