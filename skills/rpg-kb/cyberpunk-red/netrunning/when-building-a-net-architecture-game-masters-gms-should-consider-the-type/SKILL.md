# When building a NET Architecture, Game Masters (GMs) should consider the type

When building a NET Architecture, Game Masters (GMs) should consider the type and purpose of the architecture, factoring in the necessary balance between budget and operational needs. Not all electronics require a NET Architecture, such as devices that operate on the ChiNet and memory chips, like Agents and Cameras, which cannot be hacked using the Interface Role Ability. This necessitates that many Netrunners hone their Electronics/Security Tech Skills, as the Interface Role is limited to certain NET-integrated devices.
