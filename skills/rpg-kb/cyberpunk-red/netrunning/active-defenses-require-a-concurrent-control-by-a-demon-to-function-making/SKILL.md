# Active Defenses require a concurrent control by a Demon to function, making

Active Defenses require a concurrent control by a Demon to function, making them akin to autonomous robots that can cover defended areas. They include devices like drones that can attack or observe intruders. When not manually controlled by a Netrunner, these systems can be countered and reprogrammed by using the Electronics/Security Tech Skill within proximity.
