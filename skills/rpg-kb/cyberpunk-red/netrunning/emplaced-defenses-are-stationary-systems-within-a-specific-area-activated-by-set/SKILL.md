# Emplaced Defenses are stationary systems within a specific area, activated by set

Emplaced Defenses are stationary systems within a specific area, activated by set triggers. Not requiring active control, they engage intruders using preset routines, but are also susceptible to being countered by the Electronics/Security Tech Skill. This allows them to be remotely controlled or neutralized if necessary.
