# A Netrunner uses the Eye-Dee ability during a NET Action to identify

A Netrunner uses the Eye-Dee ability during a NET Action to identify the content and value of found data files. Some files require beating a Difficulty Value (DV) to gain information. In the example given, a DV9 dummy file was identified with an Interface roll of 7 plus the roll surpassing 9, but the file was useless, placed to waste a Netrunner's time.

Source path for review: Cyberpunk RED Core Book > Netrunning > How to Read the Black ICE Program Table [summary; loc 471384].
