# Examples of Netrunner Programs include Boosters like 'Eraser' which increases Cloak

Examples of Netrunner Programs include Boosters like 'Eraser' which increases Cloak Checks, 'See Ya' for Pathfinder Checks, and 'Speedy Gonzalvez' to enhance Speed. Defenders like 'Armor' can reduce brain damage, while Attackers such as 'Banhammer' can directly damage other Programs. Attacker programs automatically deactivate post-attack.
