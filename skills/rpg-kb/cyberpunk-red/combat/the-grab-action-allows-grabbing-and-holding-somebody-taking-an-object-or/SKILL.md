# The Grab action allows grabbing and holding somebody, taking an object, or

The Grab action allows grabbing and holding somebody, taking an object, or escaping a grapple. It requires DeX + Brawling Skill and can lead to a Grapple condition where both parties suffer movement and action penalties.
