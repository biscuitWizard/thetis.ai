# Ranged combat is resolved using a system where the attacker's Reflex (REF)

Ranged combat is resolved using a system where the attacker's Reflex (REF) stat, weapon skill, and a 1d10 roll are compared against either a defender's set difficulty value (DV) based on weapon and range, or the defender's Dexterity (DEX), evasion skill, and a 1d10 roll. Armor can reduce the damage taken.

Source path for review: Cyberpunk RED Core Book > Combat > Melee Weapons in Combat [summary; loc 392846].
