# Autofire is a special attack mode that requires using 10 bullets and

Autofire is a special attack mode that requires using 10 bullets and relies on the Autofire skill instead of the usual weapon skill. It is a patterned attack rather than individual bullets, providing speed and efficiency in combat, though it cannot be combined with aimed shots.
