# Melee combat in the game involves using weapons that are either swung

Melee combat in the game involves using weapons that are either swung or stabbed, including using parts of your body for attacks. It contrasts with firearms combat, as melee is typically closer range and involves different combat mechanics. Melee weapons are classified by their type and examples include combat knives, baseball bats, and lead pipes.
