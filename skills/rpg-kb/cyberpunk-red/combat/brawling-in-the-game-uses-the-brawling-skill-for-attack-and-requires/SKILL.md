# Brawling in the game uses the Brawling Skill for attack and requires

Brawling in the game uses the Brawling Skill for attack and requires dealing damage based on the attacker's Body Stat. Cyberarms guarantee a minimum damage output. Armor affects brawling differently than melee; it doesn't ignore half the Defender's armor, unlike melee weapons.

Source path for review: Cyberpunk RED Core Book > Combat > The Golden Rules of Cover [summary; loc 408915].
