# Reloading in combat requires using an action to replace a magazine with

Reloading in combat requires using an action to replace a magazine with a single type of ammunition, as mixing different ammunition types in a magazine is not allowed.

Source path for review: Cyberpunk RED Core Book > Combat > Armor Breaking Combination [summary; loc 400117].
