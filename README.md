# Retrieval benchmark results

Generated by `.github/workflows/retrieval-bench.yml`. Do not edit by hand.

- `results.jsonl` — one datapoint per line, schema 1. Appendable.
- `results.svg` — the chart. Solid lines are dense ranking, dashed are
  the BM25 fallback; the two are never joined, because they measure
  different code paths and differ by roughly 0.3 nDCG on this corpus.
- `table.txt` — the same numbers as text.

To read the series locally:

    git show bench-results:results.jsonl > /tmp/results.jsonl
    ./scripts/retrieval-bench/plot.py /tmp/results.jsonl

To add historical datapoints, run the workflow manually with a
`rev_range` such as `HEAD~20..HEAD`, or locally:

    ./scripts/retrieval-bench/run.sh --last 20 --out /tmp/results.jsonl
